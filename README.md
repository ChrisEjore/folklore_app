# Bedtime Stories: African Folklore & Voice Studio 🌍✨

Bedtime Stories is a modern Android application designed to preserve and share the rich heritage of African folklore through immersive storytelling. It combines traditional oral history with modern technology, allowing parents to narrate legendary tales in their own voices for their children.

## 🚀 Features

### 📖 Immersive Story Library
*   **Extensive Folklore**: A vast collection of African stories categorized into **Fables**, **Myths**, **Action**, **Adventure**, **Thriller**, **Horror**, and **Romance**.
*   **Legendary Tales**: Includes iconic stories like *Luanda Magere*, *Queen Amina*, *Sundiata Keita*, and the clever tales of *Anansi the Spider*.
*   **Rich Illustrations**: Multiple inline images within each story that visually explain the narrative as the child reads or listens.
*   **Moral Lessons**: Every story concludes with a highlighted moral lesson to reinforce values and wisdom.

### 🎙️ Parent Voice Studio
*   **Real Voice Recording**: A built-in studio allowing parents to record their actual voice narrations using the device's microphone.
*   **Personalized Experience**: Children can listen to their parents' unique voices even when they are not physically present.
*   **Audio Management**: Easily save and manage voice recordings linked to specific stories.

### 🔊 Smart AI Narrator
*   **Natural Voice Selection**: Uses advanced Text-to-Speech (TTS) to find natural-sounding voices (like Zara).
*   **Dynamic Tones**: The narrator automatically adjusts pitch and speed based on the genre (e.g., a suspenseful slow tone for Thrillers or a high-pitched energetic tone for Adventure).

### 🎨 Thematic UI & Experience
*   **Transforming Backgrounds**: The reader UI changes its background gradient dynamically based on the story's theme (e.g., Savannah greens for Fables, Celestial purples for Myths).
*   **Parental Controls**: Built-in age filtering to ensure content is appropriate for the child.
*   **AI Story Writer**: Generate personalized stories featuring your child as the hero using a simple prompt system.

## 🛠️ Tech Stack
*   **Language**: Kotlin
*   **UI Framework**: Jetpack Compose
*   **Architecture**: MVVM (Model-View-ViewModel)
*   **Image Loading**: Coil
*   **Audio**: MediaRecorder API & Text-to-Speech (TTS)
*   **Navigation**: Jetpack Compose Navigation

## 📦 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/ChrisEjore/staffregistration_app.git
    ```
2.  **Open in Android Studio**:
    *   Ensure you have the latest version of Android Studio (Hedgehog or later recommended).
3.  **Build & Run**:
    *   Sync Gradle files and run the `app` module on an emulator or physical device (Android 8.0+ recommended for full audio features).
